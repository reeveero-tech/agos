# ADR-0002 — منع الحذف وبروتوكول الإيقاف المنظَّم

- **الحالة:** مقبول — 2026-10-21
- **البنود:** R-G-001, R-G-002, R-G-007

## القرار
لا يُحذف شيء أبداً (GOVERNANCE G2). عند تقادم ملف/صنف/دالة:

1. **يبقى في مكانه ويعمل.**
2. يضاف في رأسه (docstring أو تعليق) سطر: `DEPRECATED (R-xxx): use <البديل>` مع رابط البند.
3. يستدعي عند الاستخدام `warnings.warn(..., DeprecationWarning, stacklevel=2)` إن كان كوداً قابلاً للتنفيذ.
4. **الأفضل دائماً:** تحويله إلى واجهة (facade) تفوّض إلى التنفيذ المعتمد، فيبقى متصلاً وحياً بدل أن يصبح ميتاً.
5. يُسجَّل في `docs/architecture/DEPRECATIONS.md` (البند، البديل، التاريخ).

الملفات المتقادمة القائمة (مثل `agos/push_to_github.sh` الذي يستهدف مستودعاً آخر، و`replit.md`) تُعلَّم ولا تُحذف.

## الإنفاذ
