# ADR-0003 — مستويات الحياة (Liveness) لكل وحدة

- **الحالة:** مقبول — 2026-10-21
- **البنود:** R-G-004, R-Q-003

## السياق
المطلوب «إحياء كل كود وكل ملف وربط كل شيء». يلزم مقياس موضوعي قابل للحساب آلياً.

## القرار
| المستوى | الاسم | الشرط (يُحسب آلياً) |
|---|---|---|
| L0 | ميت | ملف واحد على الأقل يفشل في الاستيراد |
| L1 | قابل للاستيراد | كل الملفات تُستورد |
| L2 | متصل | الحزمة قابلة للوصول من نقطة دخول تشغيلية (مسار الإقلاع / CLI) عبر رسم الاستيراد أو السجل الموحد |
| L3 | مختبَر | وحدة اختبار واحدة على الأقل تستوردها |
| L4 | حقيقي | L2 + L3 + صفر دوال فارغة (stub) |

- الحساب: `tools/audit/inventory.py` ثم `tools/audit/module_register.py` ← `docs/architecture/MODULE_REGISTER.md`.
- وثائق المواصفات (L0 بطبيعتها) هدفها: أن يكون لكل وثيقة كود ينفذها واختبار يتحقق منها (R-W1-024).
- **تعريف اكتمال الإحياء:** كل حزم الكود في L4.
