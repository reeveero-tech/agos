## 1) قراءة لقطة مراجعة ثابتة فعلاً — الربط المثبت الوحيد

- كل مصدر له معرّف مراجعة (git): تُؤخذ **لقطة مستقلة من المراجعة نفسها**
  (`git archive` للمراجعة تُستخرج إلى دليل مؤقت) والمحلل يقرأها — فهي
  محتوى المراجعة نفسه بمعزل عن أي تغييرات محلية في الشجرة الحية؛
  والإسناد إليها مثبت: `actual_context = المراجعة`، مع إعلان صريح في
  `analysis_scope` («التحليل لمحتوى المراجعة لا التغييرات المحلية»)
  وهوية المصدر الأصلية (المسار) منفصلة عن مسار اللقطة المؤقت.
- **لا ترقية بفحوص حالة**: تحليل الشجرة الحية (مصدر بلا git أو تعذر
  الأرشفة) سياقه **غير متحقق دائماً** — `_git_head` صارت معرّف المراجعة
  فقط (بلا فحص نظافة)، ولا فحص ثالث ولا بصمة وصفية بديلة.
- **مختبر (الحاسم عبر run(RESEARCH))**: تغيير ملف **المصدر الأصلي** عند
  دخول التحليل (requirements.txt ← django>=4) ثم استعادة بايتاته بعد
  قراءة المحلل وقبل عودته — **يُثبت المحتوى المقروء**: كشف المحلل flask
  (المحتوى الملتزم في اللقطة) لا django (التغيير المحلي في الحية) —
  فالإسناد إلى H صحيح والتعارض المُحقَّق معلن (المسار 1: قراءة لقطة H
  المستقلة فعلاً). ومصدر بلا git يُحلَّل حياً فيبقى سياقه غير متحقق دائماً
  وتناقض دعاوى المرسل منفصل (المسار 2).

## 2) الحالات السابقة محفوظة

- حالة الشجرة الوسخة في اختبار الوصول صارت تُثبت المسار نفسه: الكشف flask
  (اللقطة) لا django (الوسخة)، والإسناد مثبت، و`analysis_scope` معلن.
- رفض مسار الدعوى غير المطابق لمصدرها، وعزل العضو غير المتحقق في
  `_cross_source_view`، وبقية الحالات — كلها محفوظة كما في 0058.
