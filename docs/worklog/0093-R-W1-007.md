# 0093 — [R-W1-007] تثبيت إكمال المادة 16: اختطاف المخرجات بالرابط الرمزي + تغطية main.py سلوكياً

التاريخ: 2026-10-25 · الحالة: مُسلَّم

## البند

قرار المالك: «تابع تنفيذ بقية مواد خريطة الأدلة بعد إكمال حراسة منافذ
الكتابة» — مراجعة الشريحة 0092 (قبل فتح مواد جديدة) حددت نقطتي تثبيت
لاكتمال المادة 16: المخرجات المحوّلة خارج الشجرة لم تكن محروسة عند
مدخلها، ومنفذ main.py موصول بالحارس بلا تغطية سلوكية.

## ماذا تغيّر

- **أحمر أولاً (4 اختبارات فاشلة قبل الإصلاح):** (أ) سيناريو اختطاف
  المخرجات: رابط رمزي من دليل `output` نحو داخل شجرة النواة — السكربت
  التشغيلي (run_brain كمثال مختبر من المجموعة) كان يكتب نتائجه داخل
  الشجرة **وينجح** (returncode 0)، والمُنهي ينشئ أدلة تقاريره داخلها،
  ومحرك الحضارة يقبل مسار مخرجات يحل داخلها. (ب) منفذ main.py بلا تغطية
  سلوكية (حد معلن في 0092).
- **الإصلاح الأدنى:** (أ) دالة واحدة في الحارس نفسه
  `resolve_output_dir(base)` — ترفض المسار إن حل داخل شجرة النواة
  (حل المسار الحقيقي يكشف الرابط الرمزي) وتعيده وإلا؛ وُصلت بكل مداخل
  المخرجات المحوّلة: السكربتات التشغيلية ومحرك الحضارة عند تعيين مسار
  المخرجات، والمُنهي عند تعريف دليلي التقارير والأدلة (فشل صريح وقت
  الاستيراد). (ب) main.py: استخراج `save_dna_report(dna, output_file)`
  من جسم main (الحارس نفسه قبل الفتح — بلا تغيير سلوك) فصار قابلاً
  للفحص سلوكياً.
- **تصحيح عدّ توثيقي (لا كود):** شريحة 0092 وثّقت «25 سكربتاً +
  المحرك» — العدّ الفعلي 24 سكربتاً والمحرك هو الخامس والعشرون (خط الأساس
  نفسه لم يتغير: 511 فحصاً قبل وبعد).

## المختبر

- الأحمر: 4 اختبارات فاشلة قبل الإصلاح ثم خضراء بعده (23 اختباراً في
  الملف مع شرائح 0091 و0092).
- `uv run python tools/quality/run_tests.py` — 1150 ناجحاً / 0 فاشلاً /
  16 متخطاة بيئية — لا انحدارات (المجموع 1166 — +4 اختبارات).
- خط أساس التجميد جُدد (511 فحصاً — مسوّغ موثق: دالة جديدة في الحارس +
  توصيلها بـ25 ملفاً داخل النطاق المجمد + استخراج save_dna_report في
  main.py)؛ تقرير التبعيات لا مشاكل فيه.

## لماذا بهذه الطريقة

- الحارس واحد (kernel_protection.py) بلا آلية ثانية موازية — دالة
  `resolve_output_dir` تغليف للحارس نفسه لا منطق جديد؛ وحل المسار الحقيقي
  هو نفسه كاشف الرابط الرمزي المعتمد منذ 0091 (لا توسيع نطاق).
- استخراج save_dna_report أدنى تغيير يجعل منفذ main.py قابلاً للفحص
  سلوكياً — الحارس نفسه قبل الفتح، بلا أي تغيير في السلوك المرسوم.
