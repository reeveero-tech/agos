# سجل العمل 0062 — R-W1-007 (تصحيح الشريحة الأولى): القاعدة بلا مواصفة unverified، والمواصفة الناقصة ليست سماحاً فارغاً، ورفض المدقق يمنع نجاح التجميع

> **تكملة (سجل العمل 0063):** بقيت فجوة «لا حكم بلا قواعد مفحوصة» — محرك
> بلا قواعد أو تصفية نطاق بلا قاعدة مطابقة كانت تُعلن امتثالاً؛ صارت
> unverified معللة. راجع 0063.

**البند:** R-W1-007 (يبقى PARTIAL — تصحيح ملاحظات المراجعة على الشريحة
الأولى قبل الدفع؛ الالتزام 9ba9868 لم يُدفع وصُحح قبل الدفع).

## تصحيحات لادعاءات 0061 (G2 — إضافة لا حذف)

- **القاعدة بلا مواصفة عبر المحرك**: كان فرع «المسار القديم يبقى حرفياً»
  يُعلن مخالفة بلا فحص (severity="error") أو امتثالاً بلا فحص (warning) —
  صُحح: حكم `unverified` معلل («قاعدة بلا مواصفة تنفيذية — لا فحص ولا
  امتثال ولا مخالفة مثبتة»). توقع test_civilization القديم عُدّل **بلا حذف
  اسمه** (G2 تحفظ الرموز ولا تفرض إبقاء الخطأ).
- **المواصفة الناقصة تمرر**: `spec.get("required_fields", [])` كان يحوّل
  المواصفة الناقصة إلى فحص فارغ ناجح — صُحح: غياب تعريف الحقول أو فراغها
  حكم `unverified` بسبب نقص المواصفة، لا امتثال بلا فحص.
- **بوابة التجميع تتجاهل الرفض**: `validate_all` كان يحسب `passed` من
  الاستثناءات فقط — صُحح: رفض المدقق أو تعذر تحققه يمنع النجاح، والسبب
  المتاح في `last_verdict` يُنقل إلى الإخفاقات.

## الاختبارات (8 للبند — 2 جديدتان + تعديل توقع القديم)
