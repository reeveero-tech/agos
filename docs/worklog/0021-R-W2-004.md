# 0021 — تصحيح لاحق لـ R-W2-003 وR-W2-004 بعد مراجعة مستقلة

- **التاريخ:** 2026-10-21
- **البنود:** R-W2-003 وR-W2-004 (بقيتا DONE — هذا تقوية لتنفيذهما بعد مراجعة).
- **السياق:** مراجعة مستقلة لالتزامي 0019 و0020 كشفت ست فجوات دقيقة. هذا الالتزام يغلقها كلها، ومعها اختبارات تثبت كل واحدة.

## ما كُشف وكيف عُولج

| # | الفجوة | الإصلاح | الاختبار المثبت |
|---|---|---|---|
| 1 | `tree_depth` كان معاملاً في `_generate_dna` فقط — لا يصل عبر `execute()`، ومفتاح الذاكرة لا يميزه (تحليلان بعمقين مختلفين على الالتزام نفسه يعيدان الـDNA الأول) | `execute` يقبل `tree_depth` من `input_data` (ويعيّن `RepositoryAnalysisInput.tree_depth` إن وُجد)، ويضمّه لمفتاح الذاكرة | `test_tree_depth_reachable_via_execute_and_cache_distinguishes_it` |
| 2 | `detect_entry_points` لم يكن يستثني المُورَّد: `node_modules/pkg/main.py` كان يُحسب نقطة دخول | استبعاد كل مسار تحت `SKIP_DIRS` | `test_vendored_code_is_not_an_entry_point` |
| 3 | تصريحات الملفات كانت تفقد مسار الملف: `backend/pyproject.toml` و`pyproject.toml` بنفس الاسم كانا يندمجان | التصريح يحمل مسار ملفه (`backend/pyproject.toml:scripts:cli`) | `test_manifest_entry_points_keep_their_manifest_path` |
| 4 | ملف تالف البنية (`main: 42` أو `bin: [1,2]` أو JSON ليس كائناً) كان يرفع `AttributeError` ويُسقط التحليل كله | تحقق أنواع قبل كل قراءة، وملف تالف يُتجاهل وحده | `test_malformed_manifests_never_break_the_analysis` |
| 5 | `directory_tree` بلا `dir_paths` كانت تخمّن من الاسم: `Makefile` (ملف بلا لاحقة ولا نقطة) كان يدخل الشجرة كمجلد | لا تخمين: المسار مجهول النوع يُعامل ملفاً، والمجلدات تُعطى صراحة (وكل المسارات الحية تعطيها) | `test_directory_tree_treats_unknown_paths_as_files` |
| 6 | `language_lines` أُضيف **في وسط** `RepositoryInfo` و`RepositoryMetrics` — يكسر البناء الموضعي القائم؛ وادعاء «لا يُقرأ `.env`» لم يكن مختبراً (كان يمكن أن يُقرأ لو كان تحت `.github`) | نقل الحقل إلى آخر كل صنف (تعليق موثق)، و`SECRET_HIDDEN_FILES` ترفض ملفات الأسرار في أي عمق حتى داخل `.github`، مع اختبار من طرف إلى طرف | `test_secret_hidden_files_never_reach_the_dna` |

- **تدقيق توثيقي:** ادعاء 0019 بأن «كل مسارات الكشف صارت واجهات له» يصح حرفياً للمسار الحي وrie والمرحلة والشريحة؛ أما محللا الحضارة والذكاء فيحتفظان بجداولهما الخاصة (لغات أوسع مثل Shell وHaskell) ويشتركان مع الوحدة في **قاعدة الوزن** (الأسطر ثم الملفات)، لا في التفويض الكامل — والتوفيق الكامل هو نطاق R-W2-006 (توحيد ذكاء المستودعات).

## التحقق
- المجموعة الكاملة: **427 / 0 / 0 / 0** (كانت 421)، بلا تراجعات عن خط الأساس؛ وكل اختبار جديد يعالج فجوة واحدة من الجدول أعلاه.
- أدوات التدقيق كلها خضراء: الجرد 524 ملفاً وفشل استيراد 0/522، والمستويات بلا unmapped، والبيئة النظيفة 491/491، وتدقيق التبعيات 0 مشاكل.
- فُحصت كل الأوامر بحالة الخروج الظاهرة (`uv run python ... 2>&1 | tail` لا يخفيها لأن أداة الاختبار تعيد رمز خروجها إلى git عبر الخطاف).
