# سجل العمل 0072 — R-W1-010: توحيد الإدراك — ADR-0012 معتمد (قرار وثائقي)

**البند:** R-W1-010 — توحيد الإدراك (`cognitive`, `cognition`) —
**DONE بوصفه قراراً وثائقياً فقط** (مخرج الخارطة ADR؛ الترحيل التشغيلي
غير منفذ — أعمال مسماة أدناه).

## المسح (وفق منهج المراجعة — تنفيذ، مدخلات، مستهلكون، اختبارات)

مسح كامل للسطحين (`agos/cognitive/` 11 ملفاً/606 أسطر، `agos/cognition/`
6 ملفات/367 سطراً) بالبحث المؤهل والعاري والنسبي وبحث الرموز لقائمة
الواجهات الرئيسية. **لم يظهر مستهلك إنتاجي في البحث المحدد** — استعمال
واحد خارج التعريفات: اختبار سلوكي لـUniversalDecisionPlatform
(test_decision_unification.py:352-363 بتأكيدات فعلية)؛ ولم يظهر اختبار
سلوكي لبقية الواجهات الرئيسية المشمولة بالبحث.

## الأدلة الحاسمة (موثقة بمراجع مثبتة وإعادة إنتاج منفذة في ADR-0012)

- **تسجيل صادق معتمد أصلاً**: cognitive/decision.py (ADR-0006/R-W1-004:
  caller-provided، لا تقييم) — بحد: وصف صنفه يعد بواجهات غير منفذة.
- **عمليات منفذة تُحفظ بحدودها**: سجلات القرارات/النوايا/السياقات/
  الأهداف/المهارات/التركيبات/الكيانات؛ فحص فراغ الخطة (فارغة ⇒ False،
  بخطوة ⇒ True)؛ create_plan ينشئ كائن خطة بخطوة واحدة من مدخلات
  المرسل؛ واختيار أول بديل في DecisionEngine سياسة ترتيب منفذة (ليست
  تقييماً).
- **حد سجل النوايا (أعيد إنتاجه)**: IntentParser يرجع معرّفاً ثابتاً
  "parsed" — نيتان ⇒ total=1 والثانية تستبدل الأولى.
- **عيبا مسار عام أعيد إنتاجهما**: RelationshipEngine.find_relationships
  ⇒ AttributeError (بالاستدعاء العام)؛ و**فجوة توصيل سجل المهارات** —
  UniversalSkillFabric سجلان مستقلان: `fabric.registry is
  fabric.composer._registry` ⇒ False وcompose لمهارة مسجلة عبر الواجهة
  العامة يرجع [].
- **ادعاءات ثابتة محددة بالأسطر**: حل القيود (17/21)، المداولة (18/69)،
  التقييم 0.8 (10)، المحاكاة (19)، الاستنتاجات النصية (8/12/16/45)،
  الاستراتيجية (8)، تقييم/تحقق core (29/33)، «قفل» المؤسسة (21/62/72)،
  الحالة/التنبؤ (29/37)، التركيب (22/30)، وقياس المهارة (38).

## القرار (ADR-0012 — معتمد)

1. تسجيل القرارات: cognitive/decision.py معتمد أصلاً (ADR-0006) بحدوده،
   مع تمييز وعود وصف الصنف غير المنفذة.
2. العمليات المنفذة تحفظ بحدودها (لا إزالة عمياء) — وحد سجل النوايا
   موثق.
3. الادعاءات الثابتة المحددة بالأدلة تزال عند التنفيذ.
4. العيبان المعاد إنتاجهما (RelationshipEngine وفجوة توصيل المهارات)
   يوثقان ويصلحان أو يعلنان في عمل مسمى.
5. لا يعين منسق إدراك — الجهات المرجعية وحدودها المعلنة: فصل النية →
   agos/agos-kernel/intelligence/intent.py (آلية محدودة معلنة)؛ التقييم
   الحسابي للاختيارات → decision-pipeline (سياسات)؛ تسجيل القرارات →
   cognitive/decision.py. التفويض بتوافق عقد لا تشابه اسم.
6. G2: كل الرموز تبقى.

## التنفيذ المتبقي (أعمال مسماة بحدود ومعايير قبول — خارج هذا البند)

1. إزالة الادعاءات غير المسندة مع إبقاء المنفذ (اختبارات تثبت الفرق).
2. إصلاح أو تعليل العيبين (الحواف؛ فجوة توصيل المهارات).
3. حد سجل النوايا (معرّفات مميزة أو تسمية الاستبدال).
4. تمييز وعود أوصاف الصنوف غير المنفذة.

**لا كود تغيّر في هذا الالتزام** — وثائقي بالكامل. R-W1-007 يبقى PARTIAL.
