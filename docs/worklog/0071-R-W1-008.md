1. مسار قبول التعلم: آلة حالات learning/runtime هي المرشح المعتمد —
   بحدود مسماة (تحقق شكلي؛ VALID ليس وحده إثباتاً لصحة المعرفة ولا كافياً
   للنشر بوصفها موثوقة).
2. منتج نتائج التجارب: EvolutionLaboratory يبقى منتج سجلات — وقبول
   نتائجه وتكاملها بمسار القبول.
3. تنسيق دورة التطور: **مؤجل** — لا دليل لتعيين مالك؛ يحتاج توصيف مصدر
   فجوات حقيقي (فجوة مستقلة).
4. فصل مسؤوليات صريح: المقيم المعتمد (ADR-0010) مرجع أحكام السياسات فقط
   — ليس إثباتاً لصحة معرفة أو قياس أو شهادة.
5. الموافقة: لا انتقال إليها دون سياسة صريحة وقرار سلطة معتمدة (البشرية حيث تفرضها السياسة) — منع غير المشروطة لا كل الآلية.
6. الشهادة والقياس والمحاكاة: ادعاءات قابلة للفحص — لا منح ثابت ولا قيم
   ثابتة تُدَّعى قياسات.
7. خريطة توحيد لكل مدخل عام (مسؤولية باقية/تفويض/تأجيل + وضع G2 ومعيار
   قبول) — في ADR-0011.
