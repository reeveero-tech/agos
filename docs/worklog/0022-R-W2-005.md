## التصميم
**مصدر واحد** هو وحدة جديدة: `agos-kernel/clone_safety.py` (مستوردة كـ`clone_safety` أو`agos.kernel.clone_safety` — نفس آلية `stack_detection`). الوحدة نقية (مكتبة قياسية فقط):

| الضمانة | التنفيذ |
|---|---|
| قائمة سماح | `check_url` — بادئات المضيفين المعروفين (github/gitlab/bitbucket/sourcehut + `file://` + صيغ SSH). **المسار المحلي المطلق مسموح** (قرص المستدعي ملكه)، والنسبي و`//host/…` مرفوضان. قابلة للتوسيع عند النداء |
| مهلة | `timeout` على عملية git (افتراضي 300 ثانية) → `CloneRejected` |
| سقوف حجم/عدد | `measure_repo` — قياس فعلي بعد الاستنساخ (عدد الملفات + البايتات، بلا `.git` وبلا روابط) مقابل حدين قابلين للضبط |
| تنظيف مؤقت دائماً | `finally` داخل `clone`: أي فشل يحذف المجلد المؤقت؛ النجاح يسلّم الملكية للمستدعي |
| حماية الروابط الرمزية | `escape_symlinks` — كل رابط يحل خارج الجذر يُرفض به المستودع كله؛ والقارئان لم يعودا يقرآن عبر روابط الملفات أصلاً |
| الفرع الافتراضي | فشل "main" ← اكتشاف الفرع الافتراضي (`git ls-remote --symref`) وإعادة محاولة واحدة. **لمن اعتمد الافتراض الاصطلاحي فقط** — فرع طلبه المستدعي صراحة ولم يوجد يُبلَّغ بخطئه بلا إعادة محاولة تخفيه |

## التحقق
- **`tests/test_clone_safety.py` (28 اختباراً بعد التوسيع):**
  - **مشوه:** 7 عناوين مرفوضة (ftp وhttp غريب ومسار نسبي و`//host` و`~` ونطاق متخفٍ وفارغ)، والمسار المحلي المطلق مسموح بموجب ملكية المستدعي، والقائمة قابلة للتوسيع عند النداء.
  - **بطيء:** git زائف ينام 30 ثانية ← مهلة ثانيتين تقتله، والمجلد المؤقت يُحذف رغم القتل.
  - **ضخم:** سقف عدد الملفات (10 > 5) وسقف الحجم (2MB > 1MB) يرفضان مع تنظيف، والقياس مُثبت مستقلاً (`measure_repo` على 10 ملفات × 100KB).
  - **رابط رمزي:** رابط يهرب خارج الجذر يرفض الاستنساخ كله؛ الرابط الداخلي مسموح؛ و`escape_symlinks` تجد الخارجي وحده؛ والقارئ لا يقرأ عبر رابط ملف إطلاقاً.
  - **الفرع الافتراضي:** مستودع master يُستنسخ حين يُطلب main (تراجع واحد)، وفرع صريح غير موجود يُبلَّغ بخطئه، و`default_branch` تُتحقق مباشرة.
  - **من طرف إلى طرف:** `provider.Clone` و`GitFetcher` يرفضان عنواناً محظوراً، والقدرة الحية تعمل عبر `file://`، وخط rie يستنسخ نسخة واحدة وينظفها (قبل/بعد متطابقان).
- **اختبار الطفرة (4 طفرات):** تعطيل التنظيف ← فشل 4 اختبارات؛ تعطيل فحص الروابط ← فشل اختبار؛ تعطيل السقفين ← فشل اختباران؛ تعطيل تراجع الفرع ← فشل اختبار. ثم إعادة الشيفرة والمجموعة خضراء.
- **المسار الحي:** `agos-analyze file:///tmp/…` ← DNA كامل بلغة رئيسية Python.
- **المجموعة الكاملة:** **439 / 0 / 0 / 0** (كانت 427)، بلا تراجعات. 16 تخطياً كلها اختبارات الشبكة (تعطل مؤقت لبيئة التشغيل عن GitHub — تُتخطى بالتصميم، وقد نجحت حين توفرت الشبكة).
- **أدوات التدقيق:** الجرد 525 ملفاً (الوحدة الجديدة) وفشل استيراد 0/523؛ `unmapped=[]`؛ البيئة النظيفة 491/491؛ تدقيق التبعيات 0 مشاكل.

## تغيّر في السلوك (مقصود)
- **استنساخ من مضيف غير معروف يُرفض** الآن في كل المسارات (كان مقبولاً). المسارات المحلية المطلقة و`file://` تعمل كما كانت.
- **مستودعات master-default لم تعد تفشل** حين يطلب أحد "main" (تراجع واحد موثق).
- **خط rie يستنسخ نسخة واحدة** لكل تحليل بدل اثنتين (وكانت الثانية تنظف نفسها، فالأثر سرعة لا تسريب).
- **ملفات الروابط الرمزية لم تعد تُقرأ** في اللقطات (كانت تُقرأ عبرها).
- **الشريحة لم تعد تتجاهل فشل الاستنساخ بصمت** — الاستثناء يُرفع الآن.
- **الحد الافتراضي:** 500MB و50,000 ملف — قابل للضبط عند كل نداء.

## حدود معروفة (موثقة لا مخفية)
- قائمة السماح ليست أمناً مطلقاً — هي حد أدنى يمنع المضيفين العشوائيين؛ الحماية الحقيقية للعناوين الداخلية (SSRF الكامل) تحتاج نطاق شبكة.
- السقوف تقاس بعد اكتمال الاستنساخ (القرص امتلأ قبل الرفض) — سقف أثناء النقل متروك لأنه يتطلب تقدماً من git نفسه.
- git الزائف لاختبار المهلة يقتل العملية كلها؛ لا اختبار لفرع التراجع أثناء المهلة تحديداً.
